# Projects

Work with an outcome and an end date. One note per project, using the **Project** template.

A project note is a *cockpit*, not an archive: goal, state of play, next actions,
decisions with reasons. Keep it short enough to re-read in thirty seconds.

**When a project ends:** set `status: done`, and move anything durable you learned
into `Concepts/`. The project note dies; the knowledge graduates. This is the single
habit that keeps a vault from turning into a graveyard.
